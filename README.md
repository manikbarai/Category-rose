## 📌 Project Purpose

**WarmPaws – Pet Care in Winter** is a modern and responsive pet-care website designed to help pet owners take better care of their pets during the winter season.

The website provides winter pet-care services with a cozy and user-friendly interface. It also includes Firebase authentication so users can securely create accounts, log in, manage their profiles, and access personalized features.

---

## ✨ Key Features

* 🐾 **Winter Pet Care Services**

  * Browse different winter pet-care services.
  * View service name, image, rating, price, and details.

* 🔐 **Firebase Authentication**

  * User Registration / Sign Up
  * Email & Password Login
  * Google Sign-In
  * Logout
  * Forgot Password
  * Password Reset
  * Profile Update
  * Display user name, email, and profile photo

* 🎠 **Interactive Hero Slider**

  * Responsive winter-themed slider using Swiper.
  * Smooth slide transitions and navigation.

* 🔔 **Toast Notifications**

  * User-friendly success and error messages using React Hot Toast.

* 🧭 **Client-Side Routing**

  * Multiple pages and navigation using React Router.
  * Protected/private routes for authenticated users.

* 🎨 **Modern & Responsive UI**

  * Winter-themed design.
  * Responsive layout for desktop, tablet, and mobile devices.
  * Smooth animations and interactive elements.

* 👤 **User Profile Management**

  * Users can update their profile information.
  * Profile name and photo are displayed dynamically.

## 🔒 Environment Variables

Firebase configuration is stored using environment variables.

Create a `.env` file in the root directory:

```env
VITE_apiKey=your_api_key
VITE_authDomain=your_auth_domain
VITE_projectId=your_project_id
VITE_storageBucket=your_storage_bucket
VITE_messagingSenderId=your_messaging_sender_id
VITE_appId=your_app_id
```

> **Note:** Do not upload your `.env` file containing sensitive configuration to GitHub.
